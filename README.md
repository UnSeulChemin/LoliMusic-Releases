# 🎵 LoliMusic

## 🇨🇳 中文

**LoliMusic** 是一款适用于 Windows 的音乐播放器，可以将来自 **YouTube、网易云音乐（NetEase）和本地文件** 的音乐整合到同一个应用中。

无需在不同平台之间切换，即可统一管理音乐、收藏歌曲并创建个性化播放列表。

### ✨ 主要功能

- 🎵 **统一音乐库**：整合不同来源的音乐。
- 📥 **音乐下载**：通过 YouTube 和网易云音乐链接下载支持的歌曲（不包括 VIP 专属内容）。
- 📂 **本地音乐**：支持导入本地音乐文件和文件夹。
- 📋 **混合播放列表**：将不同来源的歌曲添加到同一个播放列表。
- ❤️ **收藏与搜索**：轻松整理和查找音乐。
- 💾 **数据备份**：支持以 JSON 格式备份播放列表。
- 🎮 **Discord Rich Presence**：支持显示播放状态，并提供隐私设置。
- 🔄 **版本更新**：支持通过 GitHub Releases 检查新版本。

Manage your music library, save your favorite songs, and create personalized playlists without switching between different platforms.

- 🎵 **Unified music library:** Combine music from multiple sources.
- 📥 **Music downloads:** Download supported songs using YouTube and NetEase Cloud Music links (excluding VIP-exclusive content).
- 📂 **Local music:** Import individual music files or entire folders.
- 📋 **Mixed playlists:** Add songs from different sources to the same playlist.
- ❤️ **Favorites and search:** Easily organize and find your music.
- 💾 **Data backup:** Back up your playlists in JSON format.
- 🎮 **Discord Rich Presence:** Display your listening activity with privacy settings.
